# RentPal (RP) — إدارة العقارات والإيجارات

## بناء APK عبر GitHub Actions
1. أنشئ مستودعاً **Private** على GitHub وارفع **كل** محتويات هذا المجلد (lib, assets, tool, .github, pubspec.yaml, .gitignore).
2. تبويب **Actions > Build RentPal APK > Run workflow** (يعمل أيضاً تلقائياً عند أي push على main).
3. بعد انتهاء البناء نزّل `RentPal-apk` من قسم Artifacts ثم فك الضغط لتجد `RentPal.apk`.

> التوقيع ثابت (`tool/rentpal-debug.keystore`) فيمكن تثبيت كل نسخة جديدة فوق القديمة دون حذف البيانات. اجعل المستودع Private.

## الجديد في 3.5.0

- إزالة شريطي «عقود» و«تنبيهات» من الشاشة الرئيسية؛ تبقى أيقونة الجرس ونافذة التنبيهات عند بدء التشغيل.
- **ترتيب العقارات حسب اختيارك**: أيقونة الترتيب بجانب البحث (يدوي بالسحب والإفلات / الاسم / الأحدث / الإيجار / الاستحقاق / الحالة). ترقية قاعدة البيانات إلى الإصدار 7 (آمنة).
- **بحث متقدم** شامل (نص في كل الحقول + الحالة + النوع + الاستحقاق + العقد + نطاق الإيجار + رصيد/مرافق) بجانب البحث السريع.
- إزالة أنواع العقار (شقة / محل / مصنع) من النموذج والبحث؛ أيقونة موحدة لكل العقارات.
- إزالة تحديد الموقع على خريطة جوجل (وحذف مكتبتي الخريطة والموقع ومفتاح الخريطة)؛ يبقى حقل الوصف النصي للموقع.

## الجديد في 3.2.0 — المستأجرون ورسائل العقد
- تبويب جديد **المستأجرون** في الشريط السفلي: لكل مستأجر عدّاد **الأيام المتبقية على موعد الإيجار** وعدّاد **الأيام المتبقية على تجديد العقد** بألوان (أحمر متأخر/منتهي • برتقالي قريب • أخضر مطمئن).
- بحث بالاسم، وفلاتر سريعة (الكل / متأخر / إيجار قريب / عقود قريبة) وترتيب حسب الأقرب استحقاقاً أو انتهاءً. أزرار سريعة لكل مستأجر: سداد • تجديد • رسالة العقد.
- **رسالة بقيمة العقد الجديدة** (واتساب): تعديل الإيجار والكهرباء والمياه والغاز، نص الرسالة يتولّد تلقائياً ويمكن تعديله، مع خيار حفظ القيم الجديدة في العقار.
- نافذة **تجديد العقد** فيها خيار إرسال رسالة واتساب بالتاريخ والإيجار الجديدين بعد التجديد مباشرة.
- زر «رسالة بقيمة العقد الجديدة» في بطاقة العقار أيضاً. لا تغيير في قاعدة البيانات (الترقية آمنة).

## النسخ الاحتياطي
من **الإعدادات > النسخ الاحتياطي والاستعادة**:
- **المجلد:** `/storage/emulated/0/RealEstateBackups` (التخزين الداخلي) ويمكن تغييره. عند أول مرة اضغط «منح الصلاحية» وفعّل «السماح بإدارة كل الملفات».
  إن لم تُمنح الصلاحية تُحفظ النسخ في مجلد خاص بالتطبيق كحل بديل.
- **نسخ احتياطي الآن:** ملف ZIP فيه قاعدة البيانات كاملة + كل الصور المرفقة.
- **نسخ تلقائي:** كل عدد ساعات تختاره، مع الاحتفاظ بآخر 5–30 نسخة تلقائية (النسخ اليدوية لا تُحذف).
  يعمل في الخلفية (WorkManager) ويُفحص أيضاً عند كل تسجيل دخول.
- **استيراد/استعادة:** اختيار ملف ZIP أو الضغط على نسخة من القائمة (للحساب الرئيسي فقط).
  تُحفظ نسخة أمان `prerestore_*` تلقائياً قبل الاستبدال، ثم يُطلب تسجيل الدخول من جديد.

## نسخة احتياطية على كمبيوتر ويندوز (جديد - الإصدار 2.5.0)
خيار إضافي بجانب النسخة الأوفلاين: من **الإعدادات > النسخ الاحتياطي والاستعادة > نسخة إضافية على كمبيوتر ويندوز (شبكة)**.
- النسخة تُحفظ دائماً على الهاتف أولاً، ثم تُرفع نسخة إلى مجلد مشترك (Network Share / SMB) على الكمبيوتر — يدوي وتلقائي.
- **تجهيز الكمبيوتر:** أنشئ مجلداً > Properties > Sharing > Advanced Sharing > Share this folder > Permissions: Full Control لحسابك.
- **في التطبيق:** اكتب العنوان بالشكل `\\192.168.1.5\RealEstateBackups` + اسم مستخدم/كلمة مرور ويندوز، ثم «حفظ واختبار الاتصال».
- إن كان الكمبيوتر مغلقاً وقت النسخ تبقى النسخة «معلّقة» وتُرفع تلقائياً عند أول فرصة. ويمكن رفع أي نسخة موجودة يدوياً من قائمة النسخ (⋮ > رفع إلى الكمبيوتر).
- النسخ التلقائية على الكمبيوتر تُنظَّف أيضاً حسب «عدد النسخ المحفوظة» (اليدوية لا تُحذف).
- المكتبة المستخدمة `smb_connect` (تدعم SMB 1 / 2.0 / 2.1) وهي مضافة في `pubspec.yaml`.
